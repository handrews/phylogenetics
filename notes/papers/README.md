# Notes on papers

One file per paper, named by its key in `data/sources.yaml`
(`1961_dehm.md`, `1840b_buch.md`); a paper not yet on record keeps the
same form (`1740_tilas.md`). Each holds the owner's working
translation of the passages that matter to the trees, with page
numbers, or notes taken while reading. `1817_cuvier.md` transcribes
the classification without choosing among the four 1817 keys.

Works published before 1930 are reproduced freely. Dehm 1961 and
Rievers 1961 are reproduced from the Biodiversity Heritage Library's
open copies. Notes on four later papers (Regnéll 1955, Ubaghs 1987,
Domínguez Alonso 1999, Gil Cid & Domínguez Alonso 2002) are held
privately and are not in this repository.

`ny-reports.md` and `publisher_map.md` are bibliographic notes: the
printings of the New York State reports, and which publisher holds
which journal.
