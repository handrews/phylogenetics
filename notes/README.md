# Notes: the development record

For the owner, the assistant that built the tools, and anyone
interested in how phylohist came to be. Nothing here is needed to use
phylohist; `docs/` is for that. The `hobby` branch keeps the earlier
material this directory was pruned from.

| directory | holds | written by |
|---|---|---|
| `development/` | the plan and its milestones (`plan.md`), the semantics roadmap that fixed the data contract, the design notes on structured answers and on systems of systematics, and the owner's earlier essays on the browser, the taxonomy architecture and the graph model | owner and assistant |
| `evals/` | the write-ups of the eval runs: what was measured, what failed and whose fault it was, what changed next; the runs themselves are under `eval/runs/` | assistant |
| `audits/` | the schema audit, the audit of one source against its paper, and the running observations from reading sources against the trees | assistant |
| `reviews/` | one review per source read against its paper, under the brief in `BRIEF.md`; the audit trail behind the trees' `audit` blocks | assistant |
| `papers/` | notes on and translations of individual papers, named by source key (`papers/README.md`) | owner |
