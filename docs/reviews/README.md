# Reviews

One file per paper read against its tree during the reading rounds of
2026-09-09 and 2026-09-10, written by a model from the paper's text layer
under `BRIEF.md` and kept as the audit trail. `docs/source-observations.md`
is the digest; the corrections tables there are what was acted on. A
review's "cannot verify" stays unverified until a person reads the page.
